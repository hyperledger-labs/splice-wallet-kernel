# Wallet Integration Guide

This guide provides tailored information and examples to wallet providers and exchanges to help them integrate with the Canton Network. It tackles topics from a high level, such as the overview of the Canton Network, and explains certain workflows you will need to implement, such as creating external parties and preparing and signing transactions, in detail with examples. It's suggested that the Wallet SDK is used to simplify the majority of workflows, but additional instructions and guides are also provided.

> [!IMPORTANT]
> This guide is under active development, not all sections are complete and sections will be added and adjusted over time.
